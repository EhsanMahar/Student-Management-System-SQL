# Student Management System (SQL)

## Overview
Simple Student Management System built with MySQL. Includes schema, sample data and common analysis queries.

## Files
- `student_management.sql` — Full SQL: create DB, tables, inserts, and example queries.
- `screenshots/` — Output screenshots (optional).

## Features
- Tables: students, courses, results
- Constraints: PRIMARY KEY, NOT NULL, CHECK, DEFAULT
- Examples: JOINs, GROUP BY, ORDER BY, aggregate functions

## How to run
1. Open MySQL Workbench / CLI.
2. Run `student_management.sql`.
3. Check results with provided SELECT queries.
